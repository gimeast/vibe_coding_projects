# yt-dlp GUI

yt-dlp를 감싸는 간단한 GUI. **파이썬 표준 라이브러리만** 쓰므로 pip 설치가 필요 없다.

tkinter를 쓸 수 있으면 창 GUI로, 없으면 로컬 웹 GUI로 자동 전환한다.

## 실행

```bash
python3 ytdlp_gui.py
```

이게 전부다. 설치 단계 없음.

## 어느 방식으로 떴는지 구분하기

실행하면 터미널에 배너가 뜬다. **`GUI:` 줄을 보면 된다.**

```
==============================================================
  yt-dlp 다운로더
  yt-dlp: /home/사용자/.local/bin/yt-dlp
  ffmpeg: /home/사용자/.local/bin
  GUI:    tkinter (창이 떴습니다)          ← 창 GUI
==============================================================
```

```
  GUI:    웹 (tkinter 를 쓸 수 없어 자동 전환)   ← 웹 GUI
```

화면으로도 구분된다.

| | tkinter | 웹 |
|---|---|---|
| 창 제목 | `yt-dlp 다운로더 (tkinter)` | 브라우저 탭 |
| 페이지 상단 | — | "웹 GUI 모드" 문구 표시 |
| 저장 경로 | **찾아보기** 버튼으로 폴더 선택 | 직접 입력 |
| 종료 | 창 닫기 | 터미널에서 `Ctrl+C` |

## 옵션

| 옵션 | 설명 |
|---|---|
| `--web` | 웹 GUI 강제 |
| `--tk` | tkinter 강제 (못 쓰면 그대로 실패) |
| `--port N` | 웹 GUI 포트 고정 (기본: 임의 포트) |
| `--no-browser` | 브라우저를 자동으로 열지 않음 |

## 화면 없는 서버에서 쓰기 (SSH)

SSH로 붙은 서버에는 창도 브라우저도 없다. 웹 GUI를 고정 포트로 띄우고 터널을 뚫으면 된다.

서버에서:

```bash
python3 ytdlp_gui.py --web --port 8765 --no-browser
```

로컬 PC에서:

```bash
ssh -L 8765:127.0.0.1:8765 사용자@서버주소
```

그다음 로컬 브라우저로 `http://127.0.0.1:8765/` 에 접속한다.
서버는 `127.0.0.1`에만 묶이므로 외부에 노출되지 않는다.

## 기능

- **URL** — 영상 주소
- **저장 경로** — 기본 `~/Videos`. 없는 폴더면 자동 생성(`mkdir -p`)
- **파일명** — 비워두면 영상 원래 제목 사용. 확장자는 yt-dlp가 붙인다
- **추가 옵션** — 선택. yt-dlp 옵션을 그대로 넘긴다 (예: `--cookies-from-browser firefox`)
- **동시 다운로드** — 받는 중에도 계속 **다운로드 추가**를 누를 수 있다. 개수 제한 없음
- **작업 목록** — 작업마다 상태·진행률이 보이고, 고르면 그 작업의 로그가 아래에 뜬다
- **취소 / 끝난 작업 지우기** — 취소하면 yt-dlp 가 띄운 ffmpeg 까지 함께 끝낸다
- **yt-dlp 업데이트** — `yt-dlp -U` 실행. 사이트가 바뀌어 깨졌을 때 가장 먼저 해 볼 것
- 창을 닫거나 웹 GUI를 `Ctrl+C`로 끄면 진행 중인 작업도 같이 정리된다

### yt-dlp 가 모르는 사이트 (2차 시도)

`Unsupported URL` 로 실패하면 페이지 HTML(과 iframe 한 단계)을 직접 받아
`.m3u8` / `.mpd` / `.mp4` 주소를 찾고, 원래 페이지를 `--referer` 로 붙여 다시 받는다.
파일명을 비워 뒀으면 페이지 제목을 쓴다.

브라우저 없이 정적 HTML 만 보므로, JS 가 실행 중에 주소를 받아오는 사이트
(예: v.daum.net)는 여기서도 못 찾는다.
그때는 로그에 뜨는 안내대로 브라우저 개발자 도구(F12 → Network)에서 주소를 복사해 넣는다.

### 실패 원인 안내

yt-dlp 는 실패를 거의 다 **종료 코드 1** 하나로 돌려준다. 코드만으로는 원인을 알 수 없다.
그래서 실패하면 로그의 `ERROR:` 줄을 읽어 원인과 해결책(업데이트, 쿠키, Referer 등)을
로그 끝에 안내하고, yt-dlp 버전이 30일 넘게 묵었으면 업데이트를 권한다.

## 실행 파일 경로

PATH에 의존하지 않고 전체 경로를 쓴다.

| | 기본값 | 환경변수로 변경 |
|---|---|---|
| yt-dlp | `~/.local/bin/yt-dlp` | `YTDLP_BIN` |
| ffmpeg | `~/.local/bin` | `FFMPEG_DIR` |

설치 위치가 다르면:

```bash
YTDLP_BIN=/다른/경로/yt-dlp python3 ytdlp_gui.py
```

## 문제가 생기면

**`실패 (종료 코드 1)`** — 로그 끝의 `원인:` 줄을 본다. 가장 흔한 순서:
1. yt-dlp 가 낡음 → **yt-dlp 업데이트**
2. 모르는 사이트 → 개발자 도구에서 m3u8/mpd 주소 복사 + 추가 옵션 `--referer "페이지 주소"`
3. 로그인 필요 → 추가 옵션 `--cookies-from-browser firefox`

**`yt-dlp 를 찾지 못했습니다`** — 배너의 경로에 파일이 없다. 위 환경변수로 실제 위치를 지정한다.

**`실행 권한이 없습니다`** — `chmod +x ~/.local/bin/yt-dlp`

**영상과 음성이 따로 받아지거나 합쳐지지 않음** — ffmpeg를 못 찾는 경우다. `FFMPEG_DIR`이 `ffmpeg` 실행 파일이 **들어 있는 폴더**를 가리키는지 확인한다(파일 자체가 아니라 폴더).

**웹 GUI에서 브라우저가 안 열림** — 정상이다. 터미널에 찍힌 주소로 직접 접속하면 된다.

## 요구사항

- 파이썬 3.9 이상 (표준 라이브러리만 사용)
- yt-dlp, ffmpeg 실행 파일
- tkinter는 **선택** — 없으면 웹으로 자동 전환
